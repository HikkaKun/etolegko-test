# etolegko-test

Working repository for the agentic-git demo: code is written here, then
committed and reviewed with the `commit` / `commit_apply` / `review` tools of
`@hy-sde-org/dsh-tool-git`.

Start the task session **inside this folder** — the git tools resolve the
session's own cwd, so a session opened at a parent folder reports "not inside
a working tree".
